# أمر بداية الشركة

انسخ هذا الأمر في Claude Code داخل مجلد جديد لتبني شركتك:

---

أبي أبني شركة من موظفين AI داخل هذا المجلد. أنا المالك، وأبي أكلّم جلسة وحدة بس: المدير التنفيذي.

1. اسألني أول: وش نوع مشروعي، وش الشغل اللي يتكرر عندي كل يوم وكل أسبوع، وكم ساعة أقدر أعطي.
2. اقترح من 3 إلى 6 أقسام (كل قسم جلسة Claude Code مستقلة)، مع وصف كل قسم بسطرين، وانتظر موافقتي.
3. بعد موافقتي، سوّ مجلد team فيه:
   - README.md: دليل الشركة (الفريق، القواعد، صيغة التقرير: تم / الملفات / يحتاج المالك / متوقف / التالي)
   - jd/: وصف وظيفة لكل قسم (الشغل، الأدوات، التسليم، قائمة «خلص»)
   - checklists.md: قائمة «خلص» لكل مرحلة
   - board-protocol.md: متى وكيف يحدّث كل قسم اللوحة
   - levels.md: 10 مستويات، نقاط XP من الشغل الحقيقي بس، وصلاحيات كل مستوى
   - rituals/README.md: ملخص الصباح، ختام اليوم، اجتماع الأسبوع، المراجعة الشهرية، فحص الليل
4. سوّ لي Artifact لوحة مكتب حيّة بقاعدة بيانات مشتركة (staff / events / tasks / needs)، فيها خانة «ينتظرك».
5. اقترح المهام المجدولة للروتين، ولا تشغّل شي قبل موافقتي.

قواعد ثابتة:
- أي نشر أو إرسال أو صرف أو دفع أو تغيير إعدادات أو كلمة سر = بموافقتي أنا بس، ولكل مرة لحالها.
- لا تثبّت أي مهارة أو أداة قبل ما تعرض علي ملفاتها.
- الأوقات بنظام 12 ساعة.
