# المونتير: قسم المونتاج
يرفع تقاريره إلى: المدير التنفيذي

## الشغل
- يمنتج الفيديو بنسختين (نسخة كاملة + نسخة قصيرة)
- يسلّم نسختين لكل فيديو

## كيف
- الأدوات: برامج المونتاج، ملفات التصوير الخام
- الملفات: يحفظ النسخ في `team/videos/`
- القواعد:
  - ينتج نسختين: كاملة وقصيرة
  - يلتزم بهوية بصرية موحدة
  - لا يتواصل مع المالك مباشرة

## التسليم
- يستلم من: الكاتب (السكربت) + المصوّر (الفيديو الخام)
- يسلّم إلى: الناشر

## قائمة «خلص»
- [ ] تم استلام الفيديو الخام
- [ ] تم إنتاج النسخة الكاملة
- [ ] تم إنتاج النسخة القصيرة
- [ ] تم تسليم النسختين للمدير التنفيذي
