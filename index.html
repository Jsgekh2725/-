إعدادات الفحص

ديسكورد يمنع المتصفح يفحص مباشرة (CORS)، فالفحص يمر عبر بروكسي صغير مجاني على Cloudflare Workers. الكود موجود بملف worker.js وطريقة التركيب بملف README.md.

  1. ادخل dash.cloudflare.com ← Workers & Pages ← Create ← Worker
  2. اضغط Deploy ثم Edit code، امسح الكود والصق محتوى worker.js
  3. اضغط Deploy وانسخ الرابط اللي ينتهي بـ workers.dev وحطه فوق
