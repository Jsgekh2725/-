# النشيد الوطني السعودي — Particle Project

مشروع Web جاهز للرفع مباشرة إلى GitHub Pages. **جميع الملفات في جذر المشروع ولا توجد أي مجلدات مطلوبة.**

## التشغيل على GitHub Pages

1. ارفع جميع الملفات الموجودة في هذا المجلد إلى مستودع GitHub.
2. من **Settings → Pages** اختر **Deploy from a branch**.
3. اختر الفرع الرئيسي ثم مجلد `/ (root)`.
4. افتح رابط GitHub Pages.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة في المتصفح. إذا منع المتصفح الصوت عند الفتح المحلي، شغله عبر خادم محلي بسيط مثل Live Server أو ارفعه إلى GitHub Pages.

## الملفات

- `index.html` — الصفحة الرئيسية.
- `style.css` — التصميم والمؤثرات.
- `app.js` — الجزيئات، المشاهد، التزامن والتسجيل.
- `lyrics.js` — الكلمات والتوقيتات.
- `reference-audio.mp3` — ملف الصوت المرفق في المشروع.
- `reference-video.mp4` — الفيديو المرجعي المرفق.

## تعديل التزامن

عدّل `start` و`end` داخل `lyrics.js` فقط. كل الأرقام بالثواني.

## التسجيل

زر **تسجيل الفيديو** يحاول اختيار صيغة تسجيل مدعومة تلقائيًا. أفضل دعم يكون عادةً في Chrome/Edge على الكمبيوتر. بعض متصفحات iPhone لا تسمح بتسجيل Canvas والصوت كملف فيديو من صفحة الويب، وفي هذه الحالة استخدم تسجيل الشاشة.
