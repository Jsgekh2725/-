# صائد يوزرات ديسكورد

موقع يولّد يوزرات ديسكورد ويفحصها: ✓ يعني اليوزر متاح، ✗ يعني مأخوذ.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | صفحة الموقع |
| `style.css` | التصميم |
| `app.js` | التوليد والفحص |
| `worker.js` | بروكسي الفحص (يتركّب على Cloudflare، مو على GitHub) |
| `README.md` | هذا الملف |

---

## 1) رفع الموقع على GitHub Pages

1. سوّ مستودع جديد (Repository) في GitHub، وخلّه **Public**.
2. اضغط **Add file ← Upload files** وارفع الملفات كلها (بعد ما تفك الضغط) في جذر المستودع مباشرة.
3. اضغط **Commit changes**.
4. روح **Settings ← Pages**.
5. تحت **Build and deployment** اختر **Source: Deploy from a branch**، والفرع `main` والمجلد `/ (root)`، واضغط **Save**.
6. بعد دقيقة أو دقيقتين يصير الموقع شغال على:
   `https://اسمك.github.io/اسم-المستودع/`

---

## 2) تركيب بروكسي الفحص (مجاني، دقيقتين)

ديسكورد ما يسمح للمتصفح يفحص من أي موقع ثاني (اسمها حماية CORS)، و GitHub Pages يستضيف ملفات ثابتة بس. عشان كذا الفحص يمر عبر Worker صغير على Cloudflare.

1. سجّل أو ادخل على **https://dash.cloudflare.com**
2. من القائمة: **Workers & Pages ← Create ← Create Worker**
3. سمّه مثلاً `username-checker` واضغط **Deploy**
4. اضغط **Edit code**، امسح الكود الموجود، والصق محتوى `worker.js` كامل
5. اضغط **Deploy**
6. انسخ الرابط، يكون بهالشكل: `https://username-checker.xxxx.workers.dev`
7. افتح موقعك، اضغط زر **البروكسي** فوق، الصق الرابط واضغط **حفظ واختبار**

إذا طلع لك "شغال ✓" فكل شي جاهز.

**اختياري:** عشان محد غيرك يستخدم البروكسي حقك، عدّل هذا السطر بـ `worker.js`:
```js
const ALLOWED_ORIGIN = 'https://اسمك.github.io';
```

## طريقة الاستخدام

**النوع:**
- **ثنائي**: خانتين `ab`
- **ثلاثي**: 3 خانات `abc`
- **شبه ثلاثي**: 3 خانات + رمز `_` أو `.` مثل `a_bc`، وتقدر تختار الرمز ومكانه
- **رباعي**: 4 خانات `abcd`
- **مخصص**: تكتب النمط اللي تبيه

**الستايل:** حروف فقط / أرقام فقط / حروف وأرقام / مكرر

**أنماط التكرار** (الحرف نفسه = نفس القيمة، والمختلف = قيمة مختلفة):
- `aa12` حرفين متكررين + رقمين مختلفين، مثل `kk47`
- `111a` 3 أرقام متكررة + حرف، مثل `777q`
- `ab11` حرفين مختلفين + رقمين متكررين، مثل `xm55`
- وفيه أنماط ثانية كثير

**رموز النمط المخصص:**
| الرمز | المعنى |
|---|---|
| `L` | حرف عشوائي |
| `N` | رقم عشوائي |
| `X` | حرف أو رقم عشوائي |
| `a` `b` `c` … | حرف ثابت: نفس الحرف يتكرر وين ما انكتب، والحروف المختلفة تاخذ قيم مختلفة |
| `1` `2` `3` … | رقم ثابت بنفس الفكرة |
| `_` `.` | رمز كما هو |
| `{abc}` | نص ثابت كما هو |

أمثلة: `aabb` ← `kkzz`، `L_NN` ← `q_48`، `{x}aa` ← `xpp`

## ملاحظات

- ديسكورد يحط حد لعدد الفحوصات (Rate limit). الموقع ينتظر تلقائياً المدة اللي يطلبها ديسكورد ويكمل، بس الأفضل تخلي التأخير **1500ms أو أكثر**.
- اليوزرات الثنائية والثلاثية أغلبها مأخوذة، فلا تستغرب إذا كثرت ✗.
- "متاح" معناه إن ديسكورد قال إنه غير مأخوذ لحظة الفحص. ممكن بعض اليوزرات تكون محجوزة وما تقبل وقت التغيير.
- النتائج والإعدادات تنحفظ بمتصفحك (localStorage)، فما تضيع إذا سكرت الصفحة.
- ملف `worker.js` موجود بالمستودع عشان تنسخه بس، وجوده على GitHub Pages ما يضر.
