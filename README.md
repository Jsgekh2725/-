# Script Vault

موقع بسيط لحفظ السكربتات ونسخها أو حذفها. جاهز للنشر على GitHub Pages.

## تشغيل سريع
1. ارفع الملفات إلى Repository في GitHub.
2. من **Settings → Pages** اختر `Deploy from a branch` ثم `main` و `/ (root)`.
3. الموقع يعمل مباشرة بوضع تجريبي، لكن هذا الوضع يحفظ السكربتات في نفس الجهاز فقط.

## تفعيل الحفظ السحابي (حتى تظهر السكربتات من جهاز آخر)
1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor ونفّذ محتوى `supabase.sql`.
3. من Project Settings → API انسخ Project URL و anon/public key.
4. ضع القيم في `config.js` داخل `supabaseUrl` و `supabaseAnonKey`.
5. ارفع التعديل إلى GitHub.

**تنبيه:** إعداد SQL الحالي يجعل المكتبة مشتركة ومفتوحة للقراءة والإضافة والحذف لأي شخص يملك رابط الموقع. لا تحفظ سكربتات خاصة أو حساسة بهذا الإعداد. إذا تبي مكتبة خاصة بحسابك، يلزم إضافة تسجيل دخول وسياسات RLS خاصة بالمستخدم.

## الملفات
- `index.html`: واجهة الموقع.
- `style.css`: التصميم الداكن.
- `app.js`: منطق الإضافة والنسخ والحذف.
- `config.js`: إعدادات Supabase.
- `supabase.sql`: جدول التخزين السحابي وسياسات الوصول.
