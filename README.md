# Saudi National Anthem — Particle Project

مشروع ويب مستقل مستوحى من أسلوب الفيديو المرجعي: خلفية داكنة، نقاط خضراء مضيئة تتجمع لتكوين النص، منصة ضوئية أسفل الجزيئات، ومنطقة كود تقنية في الجزء السفلي.

## الملفات

كل الملفات موجودة في جذر المشروع، بدون مجلدات.

## التشغيل

ارفع الملفات مباشرة إلى مستودع GitHub ثم فعّل GitHub Pages. افتح الموقع من HTTPS واضغط «تشغيل».

## التسجيل

زر «تسجيل الفيديو» يستخدم MediaRecorder. أغلب المتصفحات تسجل WebM. Chrome أو Edge على الكمبيوتر هما الخيار الأكثر توافقًا.

## تعديل التوقيت

عدّل `lyrics.js` لتغيير وقت ظهور كل جملة. التوقيتات الحالية مبنية على الصوت الموجود في `reference-audio.mp3` ومدته حوالي 27 ثانية.

## ملاحظة

الصوت الموجود في المشروع هو الملف الصوتي المأخوذ من الفيديو المرجعي الذي تم إرفاقه بالمحادثة. إذا تم استبداله بتسجيل مختلف للنشيد، يجب تعديل التوقيتات في `lyrics.js` وفق التسجيل الجديد.
