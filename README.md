# ✦ RoGUI Studio — صانع واجهات روبلوكس

موقع لتصميم واجهات **Roblox GUI** بالسحب والإفلات، مع أنميشنات وتأثيرات، ويصدّر لك **سكربت Lua** ينشئ الواجهة كاملة داخل **Part** في Workspace.

## 🚀 الرفع على GitHub Pages
1. أنشئ Repository جديد في GitHub.
2. ارفع **كل الملفات** اللي داخل الـ zip في جذر الـ Repository (بدون مجلدات).
3. من **Settings ← Pages** اختر `Deploy from a branch` ثم الفرع `main` والمجلد `/ (root)` واضغط Save.
4. بعد دقيقة يصير موقعك شغال على: `https://USERNAME.github.io/REPO/`

> تقدر كمان تفتح `index.html` مباشرة من جهازك بدون رفع.

## 📁 الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `style.css` | التصميم (داكن + متجاوب مع الجوال) |
| `data.js` | الكلاسات، الخصائص، الخطوط، القوالب الجاهزة، إعدادات الأنميشن |
| `render.js` | رسم الواجهة بنفس منطق روبلوكس (UDim2، AnchorPoint، المعدلات، الـ Layouts) |
| `preview.js` | وضع التجربة ▶ (Hover، الضغط، الطراطيع، الظهور...) |
| `export.js` | توليد سكربت Lua + سكربت الأنميشن (LocalScript) |
| `app.js` | المحرر: السحب، التحجيم، المستكشف، الخصائص، الحفظ |

## ✨ المميزات
- **العناصر:** Frame، ScrollingFrame، CanvasGroup، TextLabel، TextButton، TextBox، ImageLabel، ImageButton
- **كل إضافات UI:** UICorner، UIStroke، UIGradient، UIPadding، UIListLayout، UIGridLayout، UIPageLayout، UIAspectRatioConstraint، UIScale، UISizeConstraint، UITextSizeConstraint، UIFlexItem
- **الصور بالـ ID** من التولبوكس + تحويل تلقائي لـ Decal ID إلى Image ID داخل السكربت
- **البحث:** في العناصر، القوالب، المستكشف، الخصائص، الأنميشن، والمشاريع
- **أنميشنات:** مرور (تكبير/رفع/دوران/لون/توهج)، ضغط، تأثيرات نقر (تموج، طراطيع، ألعاب نارية، لمعة، نجوم، قلوب، فقاعات، ثلج، عملات، إيموجي، صورة مخصصة، نص طائر +1، حلقة)، حركات (اهتزاز، ارتداد، جيلي، لفة...)، ظهور (انبثاق، انزلاق، سقوط، آلة كاتبة...)، حركة مستمرة (طفو، نبض، قوس قزح، دوران التدرج...)
- **إجراءات:** فتح/إغلاق/إظهار-إخفاء عنصر آخر بالاسم، إغلاق الأب، Tooltip، سحب داخل اللعبة، أصوات
- **14 قالب جاهز** + حفظ قوالبك الخاصة
- تراجع/إعادة، نسخ/لصق، اختصارات، أدوات محاذاة، تحويل Scale/Offset، شبكة ومحاذاة ذكية، معاينة بأحجام شاشات مختلفة
- **الحفظ:** في قائمة "مشاريعي" (داخل المتصفح) + سكربت جاهز للنسخ أو التحميل

## 🎮 استخدام السكربت في Roblox Studio
1. اضغط **حفظ** (أو **السكربت**) وانسخ السكربت.
2. في Roblox Studio: **View ← Command Bar**.
3. الصق السكربت واضغط **Enter**.
4. بيظهر **Part** في Workspace وداخله الـ **ScreenGui** — اسحبه إلى **StarterGui**.
5. شغّل اللعبة ▶ — سكربت `RoGUI_Runtime` يشغّل كل الأنميشنات.

> إعدادات الأنميشن محفوظة كـ Attribute اسمها `RoGUI` على كل عنصر، تقدر تعدلها من Studio مباشرة.
