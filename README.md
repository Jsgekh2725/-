# 🐍 مختبر أدوات بايثون

موقع تكتب فيه أدوات بايثون وتشغّلها مباشرة من المتصفح: تكتب الكود ثم تضغط **تشغيل**.
بايثون يعمل داخل المتصفح نفسه باستخدام [Pyodide](https://pyodide.org)، لذلك لا يحتاج الموقع خادماً ويعمل على **GitHub Pages** مجاناً.

## الملفات (كلها في نفس المكان، بدون مجلدات)

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `style.css` | التصميم |
| `app.js` | التشغيل والحفظ والمشاركة |
| `examples.js` | الأمثلة الجاهزة (تقدر تضيف أمثلتك) |
| `.nojekyll` | ملف فارغ يخلي GitHub Pages يعرض الملفات كما هي |

## طريقة الرفع على GitHub Pages

1. أنشئ مستودعاً جديداً في GitHub (Public)، مثلاً باسم `python-lab`.
2. اضغط **Add file ← Upload files**، واسحب كل الملفات من داخل الـ zip (وليس الـ zip نفسه)، ثم **Commit changes**.
3. ادخل **Settings ← Pages**.
4. في **Source** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
5. انتظر دقيقة أو دقيقتين، وسيصبح الموقع على الرابط:
   `https://اسم-حسابك.github.io/python-lab/`

> ملاحظة: الملف `.nojekyll` مخفي في بعض الأنظمة. إذا لم يُرفع فلا مشكلة، الموقع يعمل بدونه.

## المميزات

- محرر كود ملوّن مع ترقيم الأسطر والمسافات التلقائية.
- تشغيل بزر أو بالاختصار `Ctrl + Enter`.
- دعم `input()`: يظهر لك مربع إدخال، أو تكتب المدخلات مسبقاً في «إعدادات التشغيل».
- تحميل تلقائي لمكتبات مثل `numpy` و`pandas` و`matplotlib` عند استيرادها.
- تثبيت مكتبات إضافية من PyPI (المكتوبة ببايثون الخالص) من خانة «مكتبات إضافية».
- عرض رسومات matplotlib كصور داخل المخرجات.
- حفظ أدواتك في المتصفح (`Ctrl + S`) وتحميلها وحذفها لاحقاً.
- فتح ملف `.py` من جهازك، وتنزيل الأداة كملف `.py`.
- مشاركة الأداة برابط فيه الكود كاملاً.
- حفظ تلقائي للمسودة، فلا يضيع كودك عند إغلاق الصفحة.
- واجهة عربية تعمل على الجوال والكمبيوتر.

## إضافة مثال جديد

افتح `examples.js` وأضف عنصراً بهذا الشكل داخل القائمة:

```js
{
  icon: "⭐",
  title: "اسم المثال",
  desc: "وصف قصير",
  code: String.raw`print("Hello")
`
},
```

## حدود يجب معرفتها

- أول تحميل للموقع يحتاج إنترنت وقد يأخذ بضع ثوانٍ (يتحمّل بايثون نفسه)، وبعدها يتخزّن في المتصفح.
- الكود يعمل في نفس صفحة المتصفح، فالحلقة اللانهائية (`while True` بدون توقف) تجمّد الصفحة، والحل تحديثها.
- لا يمكن استخدام مكتبات تحتاج نظام تشغيل حقيقي، مثل `tkinter` و`subprocess` والوصول لملفات جهازك.
- طلبات الإنترنت تكون عبر `pyodide.http.pyfetch`، وتعمل فقط مع المواقع التي تسمح بـ CORS.
