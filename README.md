# ✦ RoGUI Studio — صانع واجهات روبلوكس

موقع لتصميم واجهات **Roblox GUI** بالسحب والإفلات، مع أنميشنات وتأثيرات، ويصدّر لك **سكربت Lua** ينشئ **Model ← Part ← ScreenGui** في Workspace، أو كود **LocalScript** يبني الواجهة وقت اللعب.

## 🚀 الرفع على GitHub Pages
1. أنشئ Repository جديد في GitHub.
2. ارفع **كل الملفات** اللي داخل الـ zip في جذر الـ Repository (بدون مجلدات).
3. من **Settings ← Pages** اختر `Deploy from a branch` ثم الفرع `main` والمجلد `/ (root)` واضغط Save.
4. بعد دقيقة يصير موقعك شغال على: `https://USERNAME.github.io/REPO/`

> تقدر كمان تفتح `index.html` مباشرة من جهازك بدون رفع.

## 📁 الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `style.css` | التصميم (داكن + متجاوب مع الجوال) |
| `data.js` | الكلاسات، الخصائص، الخطوط، القوالب الجاهزة، إعدادات الأنميشن |
| `render.js` | رسم الواجهة بنفس منطق روبلوكس (UDim2، AnchorPoint، المعدلات، الـ Layouts) |
| `preview.js` | وضع التجربة ▶ (Hover، الضغط، الطراطيع، الظهور...) |
| `export.js` | توليد سكربت Lua + سكربت الأنميشن (LocalScript) |
| `app.js` | المحرر: السحب، التحجيم، المستكشف، الخصائص، الحفظ |
| `ai.js` | مساعد الذكاء: مراجعة التصميم، صمّم لي، مولد الأيقونات |

## 🤖 الذكاء الاصطناعي (زر AI أو Ctrl+K)
- **وش الناقص؟** يفحص تصميمك ويعطيك درجة من 100 وقائمة ملاحظات، وكل ملاحظة فيها زر **✨ الذكاء يضيفها** أو **✋ أضيفها بنفسي** (يحدد لك العنصر ويشرح الخطوات).
- **صمّم لي:** تكتب وصف الواجهة والذكاء يبنيها كاملة مع الأنميشنات وأزرار الفتح والإغلاق.
- **أيقونات:** أيقونة مبنية من عناصر GUI بتأثيرات (تشتغل فوراً)، أو صورة PNG تحمّلها وترفعها على روبلوكس.
- **المزوّدين:** Pollinations مجاني بدون مفتاح، Claude، OpenAI، Gemini، OpenRouter (بمفتاحك)، أو ذكاء محلي يشتغل بدون إنترنت.
- المفتاح ينحفظ في متصفحك فقط ويروح مباشرة لشركة الذكاء.

- **المحرر:** نسخ/لصق الستايل، إضافة ظل، تغليف داخل Frame، أدوات RichText + إيموجي، ألوان أخيرة، تصدير العنصر المحدد فقط، فتح/طي المستكشف
- **البحث** في كل شيء، تراجع/إعادة، محاذاة، Scale/Offset، شبكة ذكية، معاينة بأحجام شاشات

## 🎮 استخدام السكربت في Roblox Studio
1. اضغط **حفظ** (أو **السكربت**) وانسخ السكربت.
2. في Roblox Studio: **View ← Command Bar**.
3. الصق السكربت واضغط **Enter**.
4. بيظهر **Model** في Workspace ← داخله **Part** ← داخله الـ **ScreenGui** — اسحبه إلى **StarterGui**.
5. شغّل اللعبة ▶ — سكربت `RoGUI_Runtime` يشغّل كل الأنميشنات.

> بديل: اختر وضع **LocalScript** في نافذة التصدير، والصق الكود في LocalScript داخل StarterPlayerScripts.

> إعدادات الأنميشن محفوظة كـ Attribute اسمها `RoGUI` على كل عنصر، تقدر تعدلها من Studio مباشرة.
